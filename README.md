# This is an unofficial English translation of Gochuumon wa Usagi Desu ka?? Wonderful Party!

Rumors of this project's abandonment were slightly exaggerated. The scenario translation is 82% complete. The common route, all common route branches (weekday flyers, weekend visits, etc.), Sharo's route, and Chiya's route are done.

You can learn more about the game here:
https://vndb.org/v18457

## How-To

To play the game on PC, put the contents of "Vita Patch" into /Vita3K/Vita3K/ux0/app/PCSG00786.

In case you don't have it already, get Vita3K here:  
https://vita3k.org/index.html

You can find Wonderful Party! and its DLC on NoPayStation:  
https://nopaystation.com/search?query=wonderful+party&limit=10&orderBy=completionDate&sort=DESC&missing=Show  
Please keep in mind that vitamin dumps, like the one on Nyaa, will probably not work.
